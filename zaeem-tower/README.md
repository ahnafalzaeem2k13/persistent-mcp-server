# Zaeem Tower

A responsive editorial-style website celebrating Zaeem Tower. Built as a lightweight static site with semantic HTML, custom SVG artwork, responsive CSS, and vanilla JavaScript.

## Preview locally

Run: python -m http.server 8000

Open http://localhost:8000 from this folder.

## Notes

- The tower artwork is an original illustration, not a documentary photograph or surveyed architectural rendering.
- No unsupported claims about height, exact location, age, or ownership are made.
- The page is dependency-free and designed for desktop, tablet, and mobile.
