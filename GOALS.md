# NIGHTLINE Goals

Deliver a responsive, usable NIGHTLINE interactive city website with verified desktop and iPad layouts. Preserve project source and QA evidence in Google Drive, prove cold recovery from a fresh local workspace, and publish a clean GitHub update without exposing credentials.

## Acceptance
- Chromium loads the actual site at desktop 1440×900 and iPad portrait 768×1024.
- Desktop navigation remains inline; tablet navigation collapses to a working accessible menu.
- No horizontal overflow, JavaScript exceptions, console errors, or failed requests.
- Before/after screenshots are retained in results/.
- A SHA-256-verified Drive archive restores the project after local workspace deletion.
- GitHub commit and branch update are confirmed, or the exact permission blocker is recorded.
