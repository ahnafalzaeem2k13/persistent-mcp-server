# Zaeem Tools

A free, responsive collection of 50 browser-based utilities across 11 categories. No account or backend required.

Includes calculators, converters, finance, date/time, text, developer, color, generators, file conversion, image processing and education tools.

Most processing happens locally in your browser. Currency rates use Frankfurter v2 reference data; QR images are generated through QR Server and the entered content is sent to that service. Image resizing/compression is local. The app shell can be installed and cached for offline use after its first successful load. Favorites, theme and recently used tools are saved in local browser storage.
