# Toolbox

Free, responsive, browser-based utilities. No account or backend required.

Includes calculator, scientific calculator, percentage, tip splitter, discount, BMI, unit conversion, live currency, age/date difference, timer/stopwatch, word count, case conversion, duplicate remover, line sorter, text reverser, URL slug, JSON formatter/minifier, Base64, URL encode/decode, SHA-256, password generation, color picker and contrast checker.

Core processing happens locally in your browser. Currency rates are fetched live from Frankfurter. Favorites, theme and recent tools are saved in local browser storage.
