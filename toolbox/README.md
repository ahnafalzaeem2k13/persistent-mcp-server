# Zaeem Tools

A free, responsive collection of 53 practical browser-based utilities across 11 categories. No account required.

Includes everyday calculators, converters, finance, date/time, text, developer, generators, CSV/JSON, local image processing, and PDF merge, page extraction, rotation and images-to-PDF.

PDF features use the locally bundled pdf-lib library. Image resizing/compression is local. Currency rates use Frankfurter v2 reference data. QR images are generated through QR Server and the entered content is sent to that service. The app shell and PDF library are cached for offline use after the first successful load. Favorites and recently used tools are saved in local browser storage.
