# Everyday Toolbox — Goals

Build a fast, responsive, free-to-use toolbox website with real working utilities and no account requirement.

Acceptance criteria:
- Discoverable searchable tool directory with categories and responsive layouts.
- Working calculator, unit converter, percentage, date/age, timer/stopwatch, text, developer, and color tools.
- Live currency rates with clear network/error handling; never fake rates.
- Accessible controls, keyboard support, theme toggle, favorites, recent tools, and local-only preferences.
- Browser QA at desktop, iPad/tablet, and mobile; verify tool outcomes and no console/network failures (except explicitly unavailable external currency API).
- Publish to existing public GitHub repository and verify a public live URL.
